# Lean State-Sync Spec + Property-Based Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden the `neurons_`/`_node_to_idx`/`weights_` state-sync invariant (first tested as a single example in commit `7e8cca9`) with a Hypothesis property-based test that checks it after every growth event across many generated datasets/seeds, backed by a Lean formalization of the same invariant for an experimental, documentation-only spec.

**Architecture:** Two independent artifacts, no runtime coupling. (1) `formal/` — standalone Lean 4 project formalizing the invariant as a `Prop` over an abstract `SOMState` model and proving insertion preserves it. (2) `tests/test_state_sync_property.py` — a Hypothesis property test that monkeypatches `BaseSom._add_node_to_graph` to assert the same invariant against the real implementation after every insertion event, plus a `weights_` parity check after `fit()` completes.

**Tech Stack:** Lean 4 + Lake (no Mathlib dependency — proof uses only core tactics: `omega`, `simp`, `Fin.ext`). Python: `hypothesis` (new dev dependency), `unittest.mock.patch`, existing `pytest` setup.

## Global Constraints

- No Lean→Python code generation; no runtime coupling between `formal/` and `dbgsom/`.
- No CI integration for the Lean build in this iteration — `lake build` is run locally only.
- New property test must stay within the `pytest -m "not slow"` budget (no `slow` marker).
- `hypothesis` goes into `[dependency-groups] dev` only, not `project.dependencies`.
- Property test checks `neurons_`/`_node_to_idx`/`som_.nodes()` after **every** `_add_node_to_graph` call; `weights_.shape[0]` is checked **only** after `fit()` returns (it is rebuilt at the next epoch start, not synchronously — see `dbgsom/BaseSom.py:1248-1255`).
- Lean proof must contain no `sorry`/`admit`/incomplete tactic blocks.

- [ ] **Step 1: Write the Hypothesis strategy**

Create `tests/strategies.py`:

```python
import numpy as np
from hypothesis import strategies as st
from hypothesis.extra.numpy import arrays


@st.composite
def growable_dataset(draw):
    """Small dataset + seed, sized to trigger growth within a few epochs."""
    n_features = draw(st.integers(2, 5))
    n_samples = draw(st.integers(20, 60))
    X = draw(
        arrays(
            np.float64,
            (n_samples, n_features),
            elements=st.floats(-10, 10, allow_nan=False, allow_infinity=False),
        )
    )
    seed = draw(st.integers(0, 10_000))
    return X, seed
```

- [ ] **Step 2: Write the property test**

Create `tests/test_state_sync_property.py`:

```python
from unittest.mock import patch

from hypothesis import given, settings

from dbgsom.BaseSom import BaseSom
from dbgsom.SomVQ import SomVQ
from strategies import growable_dataset


@given(growable_dataset())
@settings(max_examples=20, deadline=None)
def test_state_sync_holds_after_every_growth_event(data):
    """neurons_/_node_to_idx/som_.nodes() must stay in lockstep after each
    insertion event; weights_ syncs only once fit() has finished growing."""
    X, seed = data
    violations = []
    original = BaseSom._add_node_to_graph

    def wrapped(self, *args, **kwargs):
        original(self, *args, **kwargs)
        idx_ok = all(
            self._node_to_idx[node] == i
            for i, node in enumerate(self.neurons_)
        )
        if (
            len(self.neurons_) != len(self._node_to_idx)
            or not idx_ok
            or set(self.neurons_) != set(self.som_.nodes())
        ):
            violations.append(self.som_.number_of_nodes())

    with patch.object(BaseSom, "_add_node_to_graph", wrapped):
        som = SomVQ(
            random_state=seed, n_iter=50, max_neurons=20, lambda_=2.0
        ).fit(X)

    assert not violations, f"state desync at node counts {violations}"
    assert som.weights_.shape[0] == len(som.neurons_)
```

`lambda_=2.0` is required: the default `lambda_=115.0` sets the growing
threshold `GT = lambda_ * ||std(X)||` so high that these small (20-60 row)
datasets essentially never grow past the initial 4-neuron grid (verified
empirically: 0/30 growth events across random configs at `lambda_=115`,
30/30 at `lambda_=2.0`, all sub-second). Without this override the test
would still pass but would be checking nothing — the per-event hook would
never fire.

- [ ] **Step 2: Write the spec and proof**

Create `formal/Spec/StateSync.lean`:

```lean
/-
Formal spec for the neurons_/_node_to_idx/weights_ lockstep invariant
maintained by `BaseSom._add_node_to_graph` (dbgsom/BaseSom.py:1248-1255).
Abstract model only — no code generation, no link to the Python runtime.
-/

structure SOMState (Node : Type) (n : Nat) where
  neurons     : Fin n → Node
  nodeToIdx   : Node → Option (Fin n)
  weightsRows : Nat

def StateSync {Node : Type} {n : Nat} (s : SOMState Node n) : Prop :=
  s.weightsRows = n ∧ ∀ i : Fin n, s.nodeToIdx (s.neurons i) = some i

/-- Model of `_add_node_to_graph`: append one neuron, point its index at the
new last slot, leave every other index untouched. `weightsRows` is bumped
here for the abstract model only — in the real implementation `weights_` is
rebuilt later, at the next epoch start, which is why the Python test checks
it separately after `fit()` rather than after every insertion. -/
def insertNode {Node : Type} [DecidableEq Node] {n : Nat}
    (s : SOMState Node n) (newNode : Node) : SOMState Node (n + 1) where
  neurons := fun i =>
    if h : i.val < n then s.neurons ⟨i.val, h⟩ else newNode
  nodeToIdx := fun node =>
    if node = newNode then
      some ⟨n, Nat.lt_succ_self n⟩
    else
      match s.nodeToIdx node with
      | some j => some ⟨j.val, Nat.lt_succ_of_lt j.isLt⟩
      | none => none
  weightsRows := s.weightsRows + 1

theorem insert_preserves_sync {Node : Type} [DecidableEq Node] {n : Nat}
    (s : SOMState Node n) (newNode : Node)
    (hFresh : ∀ i : Fin n, s.neurons i ≠ newNode)
    (h : StateSync s) :
    StateSync (insertNode s newNode) := by
  obtain ⟨hRows, hIdx⟩ := h
  refine ⟨by simp [insertNode, hRows], ?_⟩
  intro i
  by_cases hi : i.val < n
  · have hval : (insertNode s newNode).neurons i = s.neurons ⟨i.val, hi⟩ := by
      simp [insertNode, hi]
    rw [hval]
    have hne : s.neurons ⟨i.val, hi⟩ ≠ newNode := hFresh ⟨i.val, hi⟩
    simp only [insertNode, hne, if_false]
    have hPrev := hIdx ⟨i.val, hi⟩
    rw [hPrev]
    congr 1
    exact Fin.ext rfl
  · have hival : i.val = n := by omega
    have hval : (insertNode s newNode).neurons i = newNode := by
      simp [insertNode, hi]
    rw [hval]
    simp only [insertNode, if_true]
    exact Fin.ext hival.symm
```
